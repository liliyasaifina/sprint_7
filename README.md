# sprint_7
## Автоматизированные тесты для сервиса ЯндексСамокат

### Описание

Набор автоматизированных тестов на Java функциональностей "Создание курьера", "Логин курьера", "Создание заказа", "Получение списка заказов".
* на функциональности Создание курьера, Логин курьера проведены негативные и позитивные тесты;
* в функциональности Создание заказа протестировано поле выбора цвета;
* проведено тестирование ключевого сценария функциональности Получения списка заказов.


### Технологии и зависимости
* Java 11
* Maven
* JUnit 4.13.2
* Rest-Assured 
* Allure JUnit4 
* AspectJ 
* Gson

### Запуск тестов
```bash
mvn clean test
```
